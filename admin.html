Connect Supabase

The admin page needs your Supabase project.

  1. Run supabase/schema.sql in the Supabase SQL Editor.
  2. Fill in SUPABASE_URL and SUPABASE_ANON_KEY in config.js.
  3. Create an admin user and add them to admins (steps are at the top of the SQL file).
